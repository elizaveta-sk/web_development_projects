# Piano Keys

An interactive browser piano for practising the notes in “Happy Birthday”.

## Features

- Plays synthesized piano-style notes without downloaded audio files
- Supports mouse, touch, keyboard, and keyboard-focus controls
- Highlights keys while they are playing
- Includes a step-by-step lyric and note guide

## Play it

Open `index.html` in a modern browser, then use the piano keys or press the matching note letters:

```text
C D E F G A B
```

Use `V` for high C. The black keys use `W`, `R`, `T`, `Y`, and `U`.
