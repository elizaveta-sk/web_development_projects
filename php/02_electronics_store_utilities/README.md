# Electronics Store Utilities

A PHP exercise that models common e-commerce operations for an electronics store.

## What it demonstrates

- Reusable functions for totals, discounts, and product-name formatting
- Array deduplication and custom sorting
- Updating inventory values by reference
- Merging supplier inventories
- String normalisation, validation, and keyword searches

## Run

Open the script through a PHP-enabled local server, or run it from the command line:

```bash
php electronics_store_utilities.php
```
