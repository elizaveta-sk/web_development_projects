# Dog Walker Authentication

An Express authentication project for a dog-walking community site. It explores account registration, password hashing with bcrypt, login sessions, and Passport's local strategy.

## What it demonstrates

- Secure password hashing
- Register, log-in, and log-out routes
- Session-based authentication
- Protected pages with Passport

This is an early learning project. It needs its missing configuration and data files restored before it can be run as a complete app.
